# 🌸 SakuraCake — Cake Shop Website

A simple and elegant cake shop website built with HTML, CSS, and JavaScript. SakuraCake showcases a cake shop through a dedicated website, combining a clean web interface with a sweet, bakery-inspired theme.

**[🌐 Live Demo](https://sakuracake-hosting.firebaseapp.com/)**

## ✨ Features

- **Cake Shop Website** — A dedicated online presence for a cake shop.
- **Visual Presentation** — Showcase the shop through a website interface.
- **Classic Web Technologies** — Built using HTML, CSS, and vanilla JavaScript.
- **Lightweight Frontend** — No frontend framework required.
- **Live Demo** — View the deployed website directly in your browser.

## 🚀 Getting Started

You can run the website locally without installing a JavaScript framework or backend.

### Prerequisites

- Git
- A modern web browser
- A code editor, such as [Visual Studio Code](https://code.visualstudio.com/) (optional)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/VincentGuo25/sakuracake-web.git
```

**2. Navigate to the project directory**

```bash
cd sakuracake-web
```

**3. Open the project**

Open the HTML entry file in your browser. Alternatively, open the project folder in Visual Studio Code and use the Live Server extension for local development.

No package installation or build step is required for a basic static website.
